# ForensicMark: 재생한 기기를 찾아내는 영상 표식

영상을 **재생한 기기마다 다른 식별 번호**를 보이지 않게 넣고, 나중에 발견된 영상(도용·재업로드본)이 **어느 기기에서 재생한 사본인지** 찾는다.
재생한 기기의 **IP·OS·브라우저·시각**은 재생 순간 자동으로 기록된다. 영상에는 무작위 번호만 들어가고 IP는 기록에만 남는다.

## 사용법 (`MarkTool.exe`)

1. **① 재생 공개**: 영상 선택 → **공개 시작**. `http://이PC주소:8080/` 재생 주소가 생긴다.
   - 누군가 그 주소를 열면, 그 기기 전용 표식 사본을 즉석에서 만들어(8초 영상 약 6초) 재생한다.
   - 재생 기록에 **식별 번호, 재생한 IP, 기기(OS · 브라우저), 시각**이 한 줄씩 쌓인다. 같은 기기가 다시 열면 같은 사본을 준다.
   - 같은 와이파이의 휴대폰에서 열려면, 처음 공개할 때 뜨는 Windows 방화벽 창에서 **허용**을 눌러야 한다.
2. **② 표식 확인**: 발견된 영상을 고르거나 끌어 놓으면, 어느 기기에서 재생한 사본인지(IP·기기·시각)와 되돌린 가공(반전·잘림 등)이 나온다.

명령행: `ForensicMark serve <영상>` / `ForensicMark check <영상> [--json 결과.json]` / `ForensicMark list` / `ForensicMark embed <영상>`(시험용)

## 무엇을 넣고, 무엇을 기록하나

| 영상에 넣는 것 (64비트) | 크기 | 의미 |
|---|---|---|
| 고유 코드 | 16비트 | 어떤 원본인지 (원본 SHA-256과 연결) |
| 개별 식별 번호 | 24비트 | 어느 재생 기록의 사본인지 (무작위 번호) |
| 위조 방지값 | 24비트 | 비밀키로 계산한 HMAC-SHA256. 비밀키 없이는 번호를 위조할 수 없고, 깨진 번호를 엉뚱한 사람으로 읽지 않는다 |

| 기록 (`data/issued.tsv`) | 내용 |
|---|---|
| IP | 재생을 요청한 기기의 IP (서버가 연결에서 직접 읽음) |
| 기기 | User-Agent에서 뽑은 OS · 브라우저 (예: Android · Chrome). 원문은 메모 칸에 보관 |
| 시각 | 재생 요청 시각 |

## 지문과 표식을 함께 쓰는 이유

| | 지문 (내용에서 뽑은 패턴) | 표식 (넣은 번호) |
|---|---|---|
| 알 수 있는 것 | **어떤 원본**인지 | **누가 재생한 사본**인지 |
| 같은 원본의 사본끼리 | 모두 같다 → 시청자 구분 불가 | 기기마다 다르다 |
| 가공에 대한 강도 | 매우 강함 (크기·비율·반전·25% 축소도 찾음) | 반전·띠·잘림·회전은 되돌려서 읽음, 아주 작게 줄이면 지워짐 |

확인 순서: ① 그대로 표식을 읽는다 → ② 실패하면 **지문**으로 어떤 원본인지 찾는다 → ③ 등록된 원본이면 **가공을 되돌려 보며**(검은 띠 제거, 반전 4가지, 가장자리 잘림 0~12%·한쪽 잘림, 회전 ±6°) 표식이 가장 뚜렷한 배치를 찾아 번호를 읽는다.
지문은 32×18 밝기 패턴을 초당 약 4장 뽑아 `data/fp/`에 저장하고, 밝기·대비를 정규화해 반전 4가지로 비교한다.

## 한계 (발표에서 밝힐 것)

- **아주 작게 줄인 영상(원본의 25% 이하)** 은 표식이 지워진다. 이때는 지문으로 원본만 확인하고 "식별 번호는 읽지 못함"으로 끝난다.
- **공모:** 여러 사본을 섞으면 번호를 읽지 못한다. 누구도 지목하지 않는다.
- **IP는 재생한 연결의 IP**다. 공유기·통신사 안쪽의 실제 사람을 특정하려면 수사기관을 통한 통신사 협조가 필요하다. VPN을 쓰면 VPN 주소가 남는다.
- **Steam 상점처럼 모두에게 같은 파일을 주는 곳에는 쓸 수 없다.** 자체 플레이어·프레스 키트·비공개 데모처럼 재생 요청을 이 서버가 받는 경로에 쓴다.
- **AI로 처음부터 다시 만든 클론에는 표식이 없다.**
- 시청자에게 **추적 표식이 들어 있다는 사실을 알린다** (재생 페이지에 한 줄 안내). 기록은 필요한 기간만 보관한다.

## 구성

| 파일 | 역할 |
|---|---|
| `MarkTool.exe` | 창: ① 재생 공개, ② 표식 확인, 재생 기록 |
| `ForensicMark.exe` | 명령행 (같은 기능) |
| `src/forensic.h` | 암호, 워터마크, 가공 되돌리기, 지문, 기록 |
| `src/server.h` | 재생 서버 (기기별 사본, IP·User-Agent 기록, 구간 요청 지원) |
| `data/` | `assets.tsv`(원본), `issued.tsv`(재생 기록), `fp/`(지문), `secret.key`(비밀키) |
| `issued/` | 기기별 사본 |
| `tests/transform_test.ps1` | 가공 20가지 시험 (`pwsh -File tests\transform_test.ps1`) |

C++와 ffmpeg만 쓴다. GPU나 AI 모델이 필요 없다. 빌드: `build.cmd` (Visual Studio 2022).

## 보안 주의

`data/secret.key`가 있어야 표식을 만들고 검증할 수 있다. 공유 저장소에 올리지 말고, 잃어버리면 기존 사본을 검증할 수 없다.
