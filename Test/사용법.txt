==============================================================
 FRAME · ForensicMark 사용법
==============================================================

영상에 보이지 않는 코드를 넣고, 도용·재업로드된 영상에서 그 코드를 다시 읽어
"어떤 원본인지, 누구의 사본인지" 찾는 도구입니다.

  - FRAME 업로드 사이트 (run_site.cmd)
      영상을 올릴 때 코드를 확인해 허용·차단·경고·계정 정지를 판정합니다.
  - 표식 도구 (MarkTool.exe)
      영상을 재생 주소로 공개하고, 발견된 영상의 코드를 확인합니다.


--------------------------------------------------------------
■ 처음 한 번
--------------------------------------------------------------

 1) 압축을 풉니다 (Windows 10/11 64비트).
 2) ffmpeg를 설치합니다. 명령 프롬프트에서:
        winget install Gyan.FFmpeg
    또는 ffmpeg.exe와 ffprobe.exe를 이 폴더에 넣어도 됩니다.
 3) (선택) 팀원 PC끼리 서로 넣은 코드를 읽어야 하면, 한 사람의
    data\secret.key를 비공개로 받아 같은 위치에 넣습니다.
    혼자 시연하면 필요 없습니다.


--------------------------------------------------------------
■ ① FRAME 업로드 사이트 (run_site.cmd)
--------------------------------------------------------------

[켜기]
  - run_site.cmd를 더블클릭하면 서버 창("FRAME judge server")이 뜨고
    브라우저에 http://127.0.0.1:8090/ 이 열립니다.
  - 서버 창을 닫으면 사이트 판정이 멈춥니다.
    다시 켜려면 run_site.cmd를 다시 실행합니다 (예전 서버는 자동으로 닫힘).

[계정]
  - 오른쪽 위 "회원가입" (아이디 2~20자, 비밀번호 4자 이상) 또는 "로그인".
  - 로그인하지 않고 "영상 올리기"를 누르면 로그인 창이 먼저 뜹니다.

[영상 올리기]
  1) "+ 영상 올리기" → 제목 입력, 영상 파일 첨부 (썸네일은 선택).
  2) 오른쪽 "보호 기능"에서 "2차 창작 허용" 체크 여부를 정합니다.
  3) "홈페이지에 영상 등록" → "업로드 보호 검사" 창이 단계별로 진행됩니다.
       단계: 계정 확인 → 코드 읽기 → 지문 비교 → 가공 되돌리기
             → 원작자·2차 창작 확인 → (코드 삽입 / 우회 가공 검사 → 제재)
       화면: 올린 영상 / 가공을 되돌린 화면 / 등록된 원본,
             64비트 코드, 지문 유사도, 찾아낸 우회 가공

[판정 기준]
  - 처음 보는 영상
      → 새 원본 등록 · 보이지 않는 코드를 넣어 저장
  - 내가 올린 원본
      → 허용
  - 남의 원본, 2차 창작 "허용"
      → 허용 (가공했어도)
  - 남의 원본, 2차 창작 "불허"
      → 업로드 불허 + 경고 1회
  - 위 경우에 우회 가공이 보이거나 경고 2회째
      → 업로드 불허 + 계정 정지

  우회 가공으로 보는 것:
    좌우·상하 반전, 회전, 가장자리 자르기, 검은 띠, 배속,
    크기·비율 변경, 화면 녹화, 코드 훼손

[정지된 계정]
  - 무엇을 눌러도 "계정이 정지되었습니다" 팝업(사유 포함)이 뜨고,
    로그아웃만 됩니다.


--------------------------------------------------------------
■ ② 표식 도구 (MarkTool.exe)
--------------------------------------------------------------

[① 재생 공개]
  1) "영상 선택…" → "공개 시작" → 재생 주소(http://이PC주소:8080/)가 나옵니다.
  2) 같은 와이파이의 휴대폰·PC에서 그 주소를 열면,
     그 기기 전용 표식 사본이 재생됩니다.
  3) 재생 기록에 식별 번호, 재생한 IP, 기기(OS·브라우저), 시각이 쌓입니다.
  - 다른 기기에서 열려면 처음에 뜨는 Windows 방화벽 창에서 "허용"을 누릅니다.

[② 표식 확인]
  - 발견된 영상을 고르거나 아래 칸에 끌어 놓으면 다음이 나옵니다.
      · 식별 번호와 고유 코드
      · 재생한 IP·기기·시각
      · 되돌린 가공 (반전·잘림·회전·화면 녹화 등)
      · 지문 유사도


--------------------------------------------------------------
■ 발표 시연 순서 (추천)
--------------------------------------------------------------

 1) A 계정으로 원본을 올립니다 (2차 창작 체크 해제).
    검사 창에서 "원본 / 코드를 넣은 영상 / 차이를 키운 그림"을 보여줍니다.
 2) 코드가 들어간 영상은 data\frame\marked\ 폴더에 있습니다.
    이걸로 반전본을 미리 만들어 둡니다.
        ffmpeg -i 코드넣은영상.mp4 -vf hflip 반전본.mp4
 3) B 계정으로 코드가 들어간 영상을 그대로 올립니다
      → 업로드 불허 + 경고 1회
 4) B 계정으로 반전본을 올립니다
      → "가공을 되돌린 화면"과 함께 계정 정지 + 팝업
 5) (선택) 재생 화면을 화면 녹화한 영상을 올립니다
      → "화면 녹화 · 둘레 배경"을 찾아냄

[리허설 후 초기화]
  - 서버 창을 닫고 data\frame 폴더를 지우면 계정·경고·원본 기록이
    처음 상태로 돌아갑니다.
  - 사이트 홈의 영상 목록은 브라우저에 저장되어 따로 남습니다.


--------------------------------------------------------------
■ 명령행 (선택)
--------------------------------------------------------------

  ForensicMark check 영상.mp4     코드 확인 (--json 결과.json 으로 결과 저장 가능)
  ForensicMark site               업로드 사이트 서버 (기본 8090번)
  ForensicMark serve 영상.mp4     재생 공개
  ForensicMark list               재생 기록 보기


--------------------------------------------------------------
■ 알아둘 점
--------------------------------------------------------------

  - 한계: 원본의 25% 이하로 아주 작게 줄이면 코드가 지워집니다.
    이때는 지문으로 어떤 원본인지만 찾습니다.
  - 화면 녹화: 영상 주변이 복잡한 전체 화면 녹화는 영상 영역을 못 찾을 수
    있습니다. 플레이어 창만 녹화하는 것이 안전합니다.
  - 비밀키: data\secret.key가 있어야 코드를 만들고 읽을 수 있습니다.
    잃어버리면 기존 코드를 읽을 수 없고, GitHub에 올리면 안 됩니다.
  - 개인정보: IP 등 개인정보는 영상에 넣지 않습니다. 영상에는 무작위 번호만
    들어가고, IP는 이 PC의 기록에만 남습니다.
